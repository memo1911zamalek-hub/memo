# تحدي الكرة | Football Quiz

لعبة أسئلة كرة قدم باللغة العربية، مبنية باستخدام HTML وCSS وJavaScript فقط.

## المميزات
- أكثر من 200 سؤال.
- ثلاثة أقسام: خمن اللاعب، انتقالات اللاعب، معلومات عامة.
- ثلاثة مستويات: سهل، متوسط، صعب.
- اختيار طول الجولة: 10 أو 15 أو 20 أو جميع الأسئلة المطابقة.
- مؤقت لكل سؤال، نقاط، تصحيح فوري، ونتيجة نهائية.
- تصميم متجاوب مع الهاتف والكمبيوتر، بتأثيرات زجاجية وثلاثية الأبعاد.

## التشغيل محليًا
افتح `index.html` في المتصفح.

## النشر على GitHub Pages
1. أنشئ مستودعًا جديدًا على GitHub.
2. ارفع الملفات الثلاثة: `index.html` و`style.css` و`script.js`.
3. افتح Settings ثم Pages.
4. من Build and deployment اختر Deploy from a branch.
5. اختر الفرع `main` والمجلد `/ (root)` ثم Save.
6. انتظر قليلًا وسيظهر رابط موقعك.

> لا تحتاج إلى تثبيت مكتبات أو تشغيل خادم. الخط المستخدم يُحمّل من Google Fonts، ويمكن للعبة العمل بخط بديل إذا لم يتوفر اتصال بالإنترنت.
